font from the Google Fonts repository at commit
`e5ee31305efa101c2cae65f44d9642df2c8f0b4d` (2023-11-07):

<https://github.com/google/fonts/blob/e5ee31305efa101c2cae65f44d9642df2c8f0b4d/ofl/notosansarabic/NotoSansArabic%5Bwdth%2Cwght%5D.ttf>
